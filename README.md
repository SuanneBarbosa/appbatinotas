# BatiNotas

Aplicativo Flutter educacional para Ensino Médio e EJA. O aluno escolhe notas musicais, configura batidas fixas ou livres, compara casos com repetição e sem repetição, ouve/explora sequências e chega à regra geral.

## Como Clonar e Rodar

### Pré-requisitos
Certifique-se de ter o [Flutter SDK](https://docs.flutter.dev/get-started/install) instalado em sua máquina.

### Clonando o repositório
Abra o terminal e execute o comando abaixo:
```bash
git clone https://github.com/SuanneBarbosa/appalgebrico.git
```

### Rodando o projeto
1. Acesse o diretório do projeto:
   ```bash
   cd appalgebrico
   ```
2. Baixe as dependências:
   ```bash
   flutter pub get
   ```
3. Execute o aplicativo:
   ```bash
   flutter run
   ```
